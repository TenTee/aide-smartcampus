Administration

L'espace d'administration regroupe tous les modules de gestion. Le menu de gauche n'affiche que les modules autorisés par votre rôle (voir Rôles et droits d'accès).

Lecture seule

Si votre rôle n'a que le droit Lecture sur un domaine, les boutons d'ajout, de modification et de suppression sont masqués (ou refusés avec un message « Accès refusé », par exemple pour les notes).
